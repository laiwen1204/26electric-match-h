# 26electric-match-h

2026 年全国大学生电子设计竞赛（TI 杯）**H 题：车载平衡滚球运动控制系统** —— 省级一等奖作品源码。

设计制作一辆载有平衡滚球运动控制装置的循线小车：小车沿黑色环形路线行驶，行驶过程中钢球在车载摆杆凹槽内保持稳定于指定位置（误差 ≤1cm）。

## 系统架构

三处理器协同，两套 MCU 间以自定义 UART 命令协议联动：

```

│  │  MSPM0G3507      │ ◄──────────────────────► │  STM32F407   │ │
│  │  循迹车主控       │   started/rejected 回显   │  摆杆控制端   │ │
│  │  car-mspm0/      │                          │ balance-stm32│ │

│   八路灰度 + MG513×2 差速                       M2006 + C610 电调 │
│   OLED 计时 / 按键 / VOFA 调参                        │         │
```

## 目录结构

| 目录 | 平台 | 职责 |
|---|---|---|
| `car-mspm0/` | MSPM0G3507 + TI CCS | 八路灰度循迹、双 MG513 电机双闭环差速控制、任务状态机、OLED 计时、按键、与 STM32 的 UART 联动 |
| `balance-stm32/` | STM32F407 + Keil MDK | M2006+C610 摆杆伺服、要求3 滚球状态机（预测制动）、要求4/5/6 稳球 PD 平衡环（双区增益调度+破粘滞脉冲） |
| `vision-maixcam/` | MaixCAM Pro | YOLO26 钢球检测、α-β 自适应跟踪器、像素→cm 标定换算、UART 上报、RTSP 图传 |

## 关键技术

- **循迹**：数字量质心位置环 PD + 速度环 PI（积分分离+前馈），位置一阶低通抑制数字台阶抖动；三路冗余停车线识别（≥4 路同亮 / 最右 2 路 / 右 3 路，主循环高频采样防漏检）+ 起跑屏蔽期防误触发
- **滚球（要求3）**：针对视觉链路约 0.3s 延迟，采用速度前馈超前预测制动的分段状态机（加速→预测制动→捕获→保持），破粘滞脉冲克服连杆死区
- **稳球（要求4/5/6）**：双区增益调度 PD——远离目标全幅输出快速追球，接近目标切换温和增益避免延迟引起的极限环；行驶中视觉短时丢帧保持摆杆水平、数据恢复自动续平衡
- **视觉**：YOLO26 检测 + 运动门关联/丢帧惯性外推的鲁棒跟踪器，置信度迟滞防抖
- **起步保护**：4s 匀加速斜坡起步，消除起步冲击导致的钢球惯性后滚
