# balance-stm32 — 摆杆平衡滚球控制端 (STM32F407)

2026 电赛 H 题摆杆控制端，Keil MDK 工程（CubeMX 配置，主代码遵循 CubeMX USER CODE 规范，可安全重新生成外设配置）。

## 硬件

- 主控：STM32F407IGH6（RoboMaster C 型开发板）
- 执行器：M2006 电机 + C610 电调（CAN 总线，位置环伺服）
- 摆杆：25cm PPR 水管凹槽 + 直径 1cm 钢球
- 视觉反馈：MaixCAM Pro 经 UART6 上报球位（`found,pos_cm` 行）
- 联动：UART1 接 MSPM0 小车主控（命令行协议）

## 代码结构（模块化拆分）

| 模块 | 职责 |
|---|---|
| `APP/BEAM/` | 电机实例、CAN 看门狗（100ms 断线切输出）、摆杆共享状态（中立点/方向/限幅/指令角） |
| `APP/VISION/` | UART6 环形缓冲、行解析、球位/速度估计（差分+一阶低通）、链路统计 |
| `APP/Q3/` | 要求3 滚球状态机：O→+5→−5cm，超前预测制动 + 破粘滞脉冲 |
| `APP/Q4/` | 要求4/5/6 稳球平衡环：双区增益调度 PD + 全幅破粘滞脉冲 + 主动阻尼冷却 |
| `APP/CMD/` | UART1 命令表（见下） |
| `APP/M2006/` | M2006 驱动：速度环 PI + 位置环 P，斜坡/死区/静摩擦补偿 |
| `bsp/` `task/` | CAN 收发 / PID / 1ms 任务调度器 |
| `Core/Src/main.c` | 初始化、任务注册、UART 中断分发（CubeMX 风格，仅 128 行） |

任务周期：beam 1ms / vision 1ms / q3 10ms / q4 10ms / 打印 100ms。

## 控制要点

- **摄像头延迟补偿**：视觉链路约 0.3s 延迟，q3 用速度前馈预测 0.65s 后位置做制动决策；q4 近目标区自动降增益防延迟极限环
- **连杆死区**：小幅连续输出在死区内无效，静止超时后打全幅脉冲破粘滞，脉冲后接主动阻尼冷却防泵振
- **中立点锁存**：连杆断电可反驱，每次启动以实时电机角为本次中立点
- **视觉丢帧容错**：短时丢帧摆杆缓回水平；行驶中（q4）长断线保持位置环不切断电机，恢复后自动续平衡

## UART1 命令协议（ASCII 行，\r\n）

| 命令 | 作用 |
|---|---|
| `q3` / `q3_stop` / `q3_status` | 启动/停止/查询 要求3 滚球 |
| `q4` / `q4_stop` / `q4_status` | 启动/停止/查询 稳 O 点平衡 |
| `q6:x.x` | 稳球在任意位置 x∈[-6,+6]cm（要求6） |
| `stop` | 全停，摆杆回平 |
| `q4kp:` `q4kd:` `q4max:` | 平衡环在线调参 |
| `kp:` `ki:` `ff:` `ks:` `lpf:` `slew:` | 电机速度环调参 |
| `poskp:` `posdead:` `posmin:` `posmax:` | 电机位置环调参 |
| `target_pos:` `target_speed:` `zero` | 电机直接控制（调试用） |
| `cam_status` `cam_dump` | 视觉链路诊断 |

q3/q4/q6 互斥（内部先停后启），启动被拒绝时回复 `qX_start_rejected` 及原因。
